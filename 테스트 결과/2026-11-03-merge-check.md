## 확인된 제한 및 주의점

1. `2_face/note_cam.py:144`에서 카메라 번호가 `1`로 고정되어 있음.
   - 현재 PC: 번호 1은 열기 실패. 번호 0은 열리지만 프레임 수신 실패(MSMF 오류).
   - 따라서 실시간 웹캠 루프 성공은 확인하지 못함. 사진 기반 검출·crop 성공과 구분해야 함.
   - 번호 설정 가능하게 하고, 카메라 사용 중인 다른 앱·권한·백엔드를 확인할 필요가 있음. 번호만 바꾸면 해결된다고 단정할 수 없음.

2. 4단계 임베딩 입력은 list/tuple 계약임.
   - `cosine_similarity(np.array([1., 0.]), np.array([1., 0.]))`: 배열의 truth value 관련 ValueError.
   - `authenticate_face(np.array([1., 0.]), .8)`: 유효하지 않은 입력으로 인증 거부.
   - 미도착 3단계가 NumPy 배열을 반환한다면 `.tolist()` 변환 또는 4단계 입력 지원 확장이 필요함. 현재 연결 실패로 판정한 것은 아님.

3. 코사인 유사도 수치 경계 사례.
   - `cosine_similarity([1e308, 1e308], [1e308, 1e308])`가 1.0 대신 NaN 반환.
   - `authenticate_face`에서 모든 비교 점수가 정확히 -1인 경우 '미등록' 대신 '비교할 수 있는 데이터 없음'으로 분류됨.
   - 일반 크기의 임베딩 기본 인증 테스트는 통과했고, 위 사례에서 오인증은 확인되지 않음.
