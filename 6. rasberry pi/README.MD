# Raspberry Pi 단일 카메라 얼굴 인증

Pi 5용 독립 실행 폴더입니다. `5-result`나 `임시통합` 폴더가 없어도 이 폴더만으로
설치·등록·인증할 수 있습니다. 기존 실행본에서 Face Mesh·SFace 임베딩·무작위
얼굴 회전 검사를 포함한 소스와 설정을 가져왔습니다.

## 설치와 실행

지원 환경: **64비트 Raspberry Pi OS / Python 3.11 또는 3.12**.
기본 권장 설치 환경은 64비트 Raspberry Pi OS Bookworm의 Python 3.11입니다.
Python 3.13 이상과 32비트 OS는 현재 MediaPipe ARM 설치 조합에서 지원하지
않으며, 설치 스크립트가 시스템 변경 전에 안내하고 중단합니다.

저장소 최상위에서:

```bash
cd "6. rasberry pi"
bash setup_pi.sh
bash run_pi.sh check --camera 0
bash run_pi.sh
```

설치에는 인터넷과 시스템 패키지 설치 권한이 필요합니다. 설치 스크립트는
Picamera2/libcamera·GPIO·음성 구성 요소와 `.venv-pi` 가상환경, Python 패키지,
YuNet/SFace/Face Landmarker 모델을 준비하고 모델 실행을 점검합니다.
카메라는 설치 중 켜지지 않으며, 위 카메라 점검 또는 앱의 카메라 시작으로
명시적으로 사용합니다. `.sh` 파일은 LF 줄바꿈을 유지합니다.

화면이 있으면 `run_pi.sh`가 GUI를 실행합니다. **사용자 등록** 탭에서 이름을
입력하고 15개의 선명한 얼굴 샘플을 등록한 뒤 **인식·기록** 탭을 사용하세요.
화면이 없으면 먼저 다음 명령으로 등록하고 콘솔 인증을 실행합니다.

```bash
bash run_pi.sh enroll --name "홍길동"
bash run_pi.sh run
```

추가 명령:

```bash
bash run_pi.sh gui                       # GUI 명시 실행
bash run_pi.sh run --no-gpio --no-voice   # GPIO/음성 없이 시험
bash run_pi.sh users                     # 등록 목록
bash run_pi.sh delete --name "홍길동"    # 지정한 등록 삭제
bash run_pi.sh check --models            # 모델 실행 점검
bash run_pi.sh test                      # 테스트 (화면 없으면 GUI 테스트만 생략)
```

스크립트는 호출 위치와 관계없이 이 폴더를 기준으로 실행합니다.
`PYTHON_BIN`으로 설치 Python을 지정할 수 있지만 apt의 Picamera2/libcamera를
불러올 수 있는 인터프리터여야 합니다. 가상환경 위치를 바꾸려면 설치와 실행
양쪽에 같은 `FACE_ACCESS_VENV`를 지정하세요. Windows 가상환경은 복사하지
않습니다.

## 인증 흐름과 설정

```text
YuNet 절전 대기 (320×180 / 5FPS)
  → 활성 영상 (640×480 / 목표 20FPS)
  → 정면 임베딩으로 본인 확인
  → 정면 → 무작위 좌/우 → 정면 → 무작위 좌/우 → 정면
  → 최종 본인 재확인 → 인증된 얼굴 기록 → 5단계 결과 처리
```

Face Mesh는 활성 인증에서만 실행하며 생성한 모델은 재사용합니다. 동작 중
임베딩은 기본 0.3초 간격으로 검사하고 마지막 정면에서는 매 프레임 확인합니다.
회전 중에는 standby의 정면 조건을 적용하지 않습니다. 얼굴 소실·여러 얼굴·
추적 단절·사람 변경·시간 초과는 실패 처리하며, 성공 결과는 한 번만 전달합니다.
탭이나 기준값 변경 시 이전 인증 세션은 폐기합니다.

- `stages/set1.json`: 절전 검출과 촬영 준비 조건.
- `stages/liveness.json`: 회전 각도, 유지 시간, 검사 제한 시간. 기본 단계당
  7초·전체 25초, 자세 유지 최소 3프레임·0.25초입니다.
- `set5.json`: GPIO 핀, 실패 횟수, 수동 개방과 음성 설정. 실제 배선에 맞춰 수정하세요.

좌우는 미리보기 화면을 기준으로 안내합니다. 기기에서 요청 방향이 반대라면
`yaw_sign`을 `-1`로 바꾸세요. 각도·시간은 실기기에서 조정할 시작값입니다.
등록은 신뢰할 수 있는 운영자가 직접 하는 절차이며, 등록 화면에서 출입
처리를 하지 않습니다. 기존 수동 개방 정책은 `set5.json`에 따릅니다.

## 데이터와 모델

등록·관측 DB는 이 폴더의 `stages/data/faces.sqlite3`, 보안 로그와 결과 사진은
`logs/`, 다운로드 모델은 `stages/models/`에 생성됩니다. 기존 `5-result`의
등록 데이터는 자동으로 복사하거나 합치지 않습니다. 얼굴 DB, 로그, 모델,
가상환경과 캐시는 Git에서 제외합니다. 모델의 버전·해시·라이선스 안내는
`stages/THIRD_PARTY.md`를 참고하세요.

`5-result.py`는 기존 5단계 결과 처리 모듈 이름이며, 이 폴더에 포함되어 있어
다른 폴더의 파일을 불러오지 않습니다.

## 검증 범위

Windows에서 통합 실행본 테스트 41개와 설치·실행 스크립트 문법 검사를
통과했습니다. 가상환경과 이 폴더 경로에 공백이 있어도 실행 인수와 한글
이름이 유지되는 것을 검사합니다. ARM Python 3.11 패키지 설치 조합은
의존성 해석으로 확인했습니다. Pi 실기기 촬영·성능·전력은 아직 검증하지
않았습니다.

Face Mesh 좌표는 RGB 영상에서 추정한 값이며 실제 깊이 측정이 아닙니다.
무작위 동작 검사는 기울인/구부린 사진, 동작별 재생 영상, 실시간 합성이나
마스크를 차단한다고 보장하지 않습니다. 실제 기기에서 정상 이용자와
사진·화면·영상 공격을 시험한 뒤 사용하세요.
