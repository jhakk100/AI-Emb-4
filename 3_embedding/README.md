# 노트북 카메라 얼굴 인식

카메라로 얼굴을 등록하고, 다음 실행부터 저장된 임베딩과 비교해 이름을 표시하는 작은 Python 데스크톱 앱입니다. 한국어 이름을 지원합니다.

## 바로 실행

현재 이 프로젝트에는 가상환경, 필요한 패키지와 모델이 설치되어 있습니다.

1. **`run.bat`을 더블클릭**합니다.
2. **카메라 시작**을 누릅니다. 기본 카메라 번호는 `0`입니다.
3. 이름을 입력하고 **이름 입력 후 얼굴 등록**을 누릅니다.
4. 밝은 곳에서 혼자 카메라를 보고 고개를 좌우로 조금씩 움직입니다. 선명한 샘플 15개를 모으면 등록이 끝납니다.
5. 초록색 테두리와 등록한 이름이 표시되는지 확인합니다. 등록되지 않은 얼굴은 노란색으로 표시됩니다.

등록은 보통 5~10초 걸리며 얼굴 크기·흐림에 따라 더 걸릴 수 있습니다. 60초 안에 완료되지 않으면 다시 시도할 수 있습니다. 같은 이름으로 다시 등록하면 기존 임베딩을 교체합니다. 등록 목록에서 선택해 삭제할 수도 있습니다.

새 PC에서는 Python 3.12 이상(Windows의 Tkinter 포함)을 설치하고 `setup.bat`을 한 번 실행한 후 `run.bat`을 실행하세요. 첫 설치에는 인터넷이 필요합니다. 이 프로젝트에서는 Windows / Python 3.14로 검증했습니다.

PowerShell에서 직접 실행하려면:

```powershell
.\.venv\Scripts\python.exe app.py
# 기본 카메라가 다른 장치라면:
.\.venv\Scripts\python.exe app.py --camera 1
```

## 어떻게 동작하나요?

```text
카메라 프레임 → YuNet 얼굴 검출 → 눈·코·입 위치로 얼굴 정렬
             → SFace 128차원 임베딩 → 등록된 임베딩과 코사인 유사도 비교
```

별도의 모델 학습 없이 사전 학습된 모델을 사용합니다. 등록할 때 샘플별 임베딩을 정규화하고 평균한 후 다시 정규화해 한 사람의 대표 벡터 하나를 저장합니다. 인식할 때 가장 유사한 등록을 찾고 기준 이상일 때 이름을 표시합니다.

기본 기준은 `0.45`입니다. 숫자는 유사도이며 확률이나 정확도 백분율이 아닙니다. 다른 사람을 본인으로 인식하면 기준을 높이고, 본인을 자주 놓치면 조명과 등록 상태를 개선한 후 기준을 조금 낮춰보세요. [OpenCV 공식 예제](https://docs.opencv.org/4.10.0/d0/dd4/tutorial_dnn_face.html)의 LFW 기준 `0.363`은 참고값이며, 이 앱의 실제 카메라 환경에서 정확도를 보장하는 값은 아닙니다.

사진·영상은 디스크에 저장하거나 외부 서버로 전송하지 않습니다. 임베딩과 이름은 `data/embeddings.json`에 평문 JSON으로 저장되므로 해당 파일도 개인 데이터로 다루세요. 앱을 다시 실행해도 등록을 유지합니다. 모델을 다운로드한 이후 인식은 인터넷 없이 동작합니다.

이 데모에는 사진·화면 재생 공격을 막는 생체 확인 기능이 없습니다. 로그인이나 출입 통제에 바로 사용하기보다는 개인 학습과 실험용으로 사용하세요.

## 카메라가 안 열릴 때

- Windows **설정 → 개인 정보 및 보안 → 카메라**에서 카메라 및 데스크톱 앱의 카메라 접근을 허용하세요.
- Teams, Zoom 등 카메라를 사용하는 앱을 닫고 다시 시도하세요.
- 카메라 번호를 `1` 또는 `2`로 바꿔보세요. Windows에서는 DirectShow를 먼저 시도하고, 프레임을 받지 못하면 MSMF로 다시 시도합니다.
- 카메라 중지 버튼이나 창 닫기로 카메라를 해제할 수 있습니다.
- 등록 파일이 손상되면 덮어쓰지 않고 오류를 표시합니다. 기존 파일을 확인하거나 다른 곳에 보관한 후 다시 등록하세요.

## 검증 명령

```powershell
# 저장·삭제·유사도 판정·등록 품질 검사
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
# 실제 모델 로딩 및 추론 검사
.\.venv\Scripts\python.exe check_setup.py
# GUI 렌더링 및 카메라 프레임 확인 (카메라가 잠시 켜집니다)
.\.venv\Scripts\python.exe check_setup.py --gui --camera 0
```

## 파일

- `app.py`: 한국어 GUI, 카메라 백그라운드 처리, 등록·인식 화면
- `face_core.py`: 얼굴 검출·정렬·임베딩, 등록 품질 검사, 저장과 비교
- `models.py`: 공식 OpenCV 모델 다운로드 및 SHA-256 검증
- `models/`: YuNet/SFace 모델 파일
- `data/embeddings.json`: 처음 얼굴을 등록할 때 생성되는 로컬 데이터
- `THIRD_PARTY.md`: 사용 모델의 출처와 라이선스

모델은 [OpenCV Zoo YuNet](https://github.com/opencv/opencv_zoo/tree/main/models/face_detection_yunet)과 [SFace](https://github.com/opencv/opencv_zoo/tree/main/models/face_recognition_sface)에서 받습니다. OpenCV 4.x와 함께 사용할 YuNet 2023mar 모델을 고정하고, 두 모델 모두 공식 Git LFS SHA-256과 일치하는지 검사합니다.
