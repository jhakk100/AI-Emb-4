DB Comparison & Authentication

1. 담당 기능

등록된 사용자의 얼굴 임베딩 데이터와 현재 입력된 얼굴 임베딩 데이터를 비교하여 사용자를 인증하는 기능입니다.

2. 주요 작업

* 현재 얼굴 임베딩 데이터 수신
* 등록된 사용자 임베딩 DB 조회
* 유사도 계산
* Threshold 기준으로 인증 여부 판단

3. 개발 환경

* Raspberry Pi 5
* Python

4. 개발 진행 상황

현재 DB 비교 및 인증 기능을 구현하고 테스트하는 단계입니다.

※ 실제 얼굴 인식 모델 및 임베딩 DB와의 연동은 팀 프로젝트 통합 과정에서 진행합니다.
