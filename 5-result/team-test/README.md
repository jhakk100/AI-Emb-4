# 팀원 인증 테스트

`faces.sqlite3`는 기존 등록과 인증 기록을 담은 테스트 시작점입니다.

1. 별도 체크아웃에서 `5-result/team-test/faces.sqlite3`를 `5-result/stages/data/faces.sqlite3`로 복사합니다. 기존 DB를 쓰고 있다면 그 파일은 따로 보관하세요.
2. `5-result/run.bat`에서 카메라를 시작한 뒤 **옵션 → 인식·기록 → 인증 10회 진단 시작**을 누릅니다.
3. 새로 얼굴을 등록하기 전에 먼저 시험합니다. 미등록 팀원에게 등록자의 이름으로 **진단 인증 성공**이 표시되면 오승인으로 기록합니다. 이미 DB에 등록된 팀원은 실제 이름과 인증된 이름을 비교합니다.
4. **인증 시도 확인 · 유사도 교차점**에서 인증 결과와 별도로 실제 인물을 확인합니다. 미등록 팀원은 **미등록 타인으로 확인**을 선택합니다.

각 팀원의 진단 로그는 `5-result/logs/auth_diagnostics/`에 저장됩니다. 이후 자기 얼굴을 등록해서 본인 인증과 다른 등록자 이름으로 잘못 인증되는 경우를 따로 확인할 수 있습니다.
